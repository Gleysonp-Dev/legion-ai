# User Flow

> Legion skill · category **UX, UI & Accessibility**

## When to use
Map user flows for a task from entry to success, including errors and alternatives. Use before designing screens.

## Procedure
1. Define the user goal and entry points.
2. List steps and decisions.
3. Add error and edge paths.
4. Remove unnecessary steps.
5. Draw as a Mermaid flowchart.

## Quality checklist
- [ ] Error paths included
- [ ] steps minimised

## Output
User flow diagram.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
