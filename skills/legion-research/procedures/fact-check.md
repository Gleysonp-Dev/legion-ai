# Fact Check

> Legion procedure `fact-check` · pack **Research & Analysis** (`legion-research`)

## When to use
Verify claims against reliable sources and rate them true, false, misleading or unverified. Use before publishing or deciding.

## Procedure
1. List each factual claim.
2. Find primary sources.
3. Compare and rate.
4. Note context.
5. Cite sources.

## Quality checklist
- [ ] Primary sources used
- [ ] ratings justified

## Output
Fact-check table.
