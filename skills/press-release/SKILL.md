# Press Release

> Legion skill · category **Writing & Communication**

## When to use
Write a press release with headline, dateline, lead, quotes, boilerplate and contact. Use for announcements.

## Procedure
1. Write a newsworthy headline.
2. Answer who, what, when, where, why in the lead.
3. Add quotes (marked as drafts for approval).
4. Add boilerplate and contact.
5. Keep to one page.

## Quality checklist
- [ ] Quotes marked for approval
- [ ] facts verified

## Output
Press release draft.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
