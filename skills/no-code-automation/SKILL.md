# No Code Automation

> Legion skill · category **Productivity & Automation**

## When to use
Design automations in Zapier, Make, n8n or Power Automate connecting apps with triggers, filters and error handling. Use for business workflows without code.

## Procedure
1. Map trigger and actions.
2. Choose platform.
3. Add filters and data mapping.
4. Add error notifications.
5. Test with real data.

## Quality checklist
- [ ] Error handling configured
- [ ] tested

## Output
Automation design and setup steps.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
