# Statistical Testing

> Legion procedure `statistical-testing` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Choose and run the right statistical test (t-test, chi-square, Mann-Whitney, regression) and explain results plainly. Use when comparing groups or testing relationships.

## Procedure
1. Clarify hypothesis and data types.
2. Check assumptions (normality, independence, variance).
3. Run the appropriate test.
4. Report effect size and confidence interval, not just p-value.
5. Explain in plain language with caveats.

## Quality checklist
- [ ] Assumptions checked
- [ ] effect size reported

## Output
Test results and interpretation.
