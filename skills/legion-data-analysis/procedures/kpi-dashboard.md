# KPI Dashboard

> Legion procedure `kpi-dashboard` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Design a KPI dashboard: metric definitions, layout, targets and refresh. Use to track business or product health.

## Procedure
1. Choose 5–8 KPIs tied to goals.
2. Define each precisely (formula, source, owner).
3. Lay out key numbers first, trends next, details last.
4. Show targets and comparisons.
5. Set refresh schedule and data freshness indicator.

## Quality checklist
- [ ] Every KPI defined
- [ ] freshness shown

## Output
Dashboard spec or implementation.
