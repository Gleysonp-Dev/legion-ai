# Exploratory Analysis

> Legion procedure `exploratory-analysis` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Run exploratory data analysis: profile, distributions, correlations, outliers and first insights. Use when receiving a new dataset.

## Procedure
1. Load data and report shape, types and missing values.
2. Summarise distributions of key variables.
3. Check correlations and segment differences.
4. Flag outliers and data-quality issues.
5. List 3–5 insights and questions for deeper analysis.

## Quality checklist
- [ ] Data issues flagged
- [ ] insights backed by numbers

## Output
EDA notebook or report.
