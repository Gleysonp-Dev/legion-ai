# Chart Maker

> Legion procedure `chart-maker` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Create a clear, honest chart from data with the right chart type, labels and a takeaway title. Use whenever data should be visualised.

## Procedure
1. Identify the message (trend, comparison, distribution, relationship).
2. Pick the matching chart type.
3. Label axes with units; start bar axes at zero.
4. Use colour to highlight the point.
5. Title the chart with the takeaway.

## Quality checklist
- [ ] Axes honest
- [ ] accessible colours
- [ ] takeaway title

## Output
Chart image or code.
