# Funnel Analysis

> Legion procedure `funnel-analysis` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Analyse conversion funnels to find where users drop off and why. Use for signup, onboarding or checkout optimisation.

## Procedure
1. Define funnel steps and the time window.
2. Compute conversion per step and overall.
3. Segment by source, device and cohort.
4. Identify the largest drop-off.
5. Suggest hypotheses to test.

## Quality checklist
- [ ] Step definitions consistent
- [ ] segments compared

## Output
Funnel chart and recommendations.
