# Survey Analysis

> Legion procedure `survey-analysis` · pack **Data Analysis & Visualisation** (`legion-data-analysis`)

## When to use
Analyse survey results: response rates, Likert scales, cross-tabs, open-text themes and bias. Use after collecting survey data.

## Procedure
1. Report response rate and respondent profile.
2. Summarise closed questions with counts and percentages.
3. Cross-tab by key segments.
4. Code open-text answers into themes.
5. Note biases and limits.

## Quality checklist
- [ ] Sample size stated
- [ ] bias discussed

## Output
Survey report.
