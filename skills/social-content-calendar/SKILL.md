# Social Content Calendar

> Legion skill · category **Marketing & Growth**

## When to use
Create a social media content calendar with post ideas, formats, captions and schedule. Use for consistent social presence.

## Procedure
1. Define pillars and platforms.
2. Plan posting frequency.
3. Write post ideas with hooks.
4. Draft captions and hashtags.
5. Schedule.

## Quality checklist
- [ ] Mix of pillars
- [ ] realistic frequency

## Output
Content calendar.

## Works well with
Legion agents: `growth-strategist`, `seo-specialist`, `social-media-manager`, `content-strategist`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
