# Rewrite Clarity

> Legion skill · category **Writing & Communication**

## When to use
Rewrite text to be clearer, shorter and easier to read while keeping meaning. Use to improve any draft.

## Procedure
1. Identify main point.
2. Cut filler and redundancy.
3. Prefer active voice and short sentences.
4. Restructure for flow.
5. Keep the author's voice.

## Quality checklist
- [ ] Meaning preserved
- [ ] shorter

## Output
Rewritten text.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
