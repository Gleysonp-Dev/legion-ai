# Feature Spec

> Legion skill · category **Product Management**

## When to use
Write a technical-friendly feature spec bridging product and engineering: behaviour, rules, states, edge cases and analytics. Use before implementation.

## Procedure
1. Describe behaviour per user type.
2. Define business rules.
3. Specify states and transitions.
4. List edge cases and errors.
5. Define analytics events.

## Quality checklist
- [ ] Edge cases covered
- [ ] events defined

## Output
Feature spec.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
