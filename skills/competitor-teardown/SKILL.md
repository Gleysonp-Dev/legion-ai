# Competitor Teardown

> Legion skill · category **Research & Analysis**

## When to use
Analyse a single competitor deeply: product, pricing, positioning, funnel, tech and weaknesses. Use to understand a rival.

## Procedure
1. Collect public information.
2. Analyse product and UX.
3. Analyse pricing and packaging.
4. Analyse marketing and positioning.
5. Summarise strengths and weaknesses.

## Quality checklist
- [ ] Public sources only
- [ ] cited

## Output
Teardown report.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
