# Financial Model

> Legion procedure `financial-model` · pack **Business & Finance** (`legion-business-finance`)

## When to use
Build a financial model with revenue, costs, cash flow, scenarios and sensitivity in a spreadsheet. Use for planning and fundraising (not personalised financial advice).

## Procedure
1. List assumptions on a separate tab.
2. Model revenue drivers.
3. Model costs.
4. Compute P&L and cash flow.
5. Run scenarios and sensitivity.

## Quality checklist
- [ ] No hard-coded numbers in formulas
- [ ] scenarios included

## Output
Financial model.
