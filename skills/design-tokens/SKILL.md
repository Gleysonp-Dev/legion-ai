# Design Tokens

> Legion skill · category **UX, UI & Accessibility**

## When to use
Define design tokens (colour, type, spacing, radius, shadow, motion) and export them to CSS/Tailwind/JSON. Use to create a consistent design foundation.

## Procedure
1. Define primitive values.
2. Create semantic tokens mapped to primitives.
3. Provide light and dark themes.
4. Export to platform formats.
5. Document usage.

## Quality checklist
- [ ] Semantic layer exists
- [ ] themes complete

## Output
Token files and docs.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
