# Docs Audit

> Legion skill · category **Documentation**

## When to use
Audit documentation for outdated content, broken links, gaps and inconsistencies. Use periodically.

## Procedure
1. Inventory pages and last-updated dates.
2. Check links and code samples.
3. Compare docs with current behaviour.
4. List gaps from support questions.
5. Prioritise fixes.

## Quality checklist
- [ ] Broken links listed
- [ ] samples tested

## Output
Docs audit report.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
