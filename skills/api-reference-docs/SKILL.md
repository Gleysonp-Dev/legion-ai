# API Reference Docs

> Legion skill · category **Documentation**

## When to use
Generate and polish API reference docs from code or OpenAPI specs. Use when developers need complete reference material.

## Procedure
1. Generate reference from source of truth.
2. Add descriptions and examples to each item.
3. Group logically.
4. Document errors and limits.
5. Publish and link from README.

## Quality checklist
- [ ] Every public item documented with example

## Output
API reference pages.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
