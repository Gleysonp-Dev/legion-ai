# Email Triage

> Legion skill · category **Productivity & Automation**

## When to use
Triage an inbox: categorise, prioritise, draft replies and set up filters. Use when email is overwhelming.

## Procedure
1. Categorise messages.
2. Prioritise by urgency and importance.
3. Draft replies for quick wins.
4. Propose filters.
5. List follow-ups.

## Quality checklist
- [ ] Urgent items surfaced

## Output
Triage summary and drafts.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
