# Deep Linking

> Legion skill · category **Mobile Development**

## When to use
Set up deep links and universal/app links with routing, fallbacks and attribution. Use for sharing links and marketing campaigns.

## Procedure
1. Configure universal links (iOS) and app links (Android).
2. Map URLs to screens.
3. Handle not-installed fallback to web or store.
4. Handle auth-required routes.
5. Test on devices.

## Quality checklist
- [ ] Works installed and not installed

## Output
Deep link configuration.

## Works well with
Legion agents: `mobile-engineer`, `ui-designer`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
