# Tutorial Writer

> Legion procedure `tutorial-writer` · pack **Documentation** (`legion-docs`)

## When to use
Write step-by-step tutorials that take a beginner from zero to a working result. Use for onboarding users or developers.

## Procedure
1. Define the end result and prerequisites.
2. Write numbered steps with commands and expected output.
3. Explain the why briefly at each step.
4. Test the tutorial from scratch.
5. End with next steps.

## Quality checklist
- [ ] Tested from clean environment

## Output
Tutorial document.
