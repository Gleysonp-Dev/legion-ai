# Diagram As Code

> Legion procedure `diagram-as-code` · pack **Documentation** (`legion-docs`)

## When to use
Create diagrams as code with Mermaid, PlantUML or D2: flowcharts, sequence, ER, state and architecture diagrams. Use to explain flows visually.

## Procedure
1. Choose diagram type for the question.
2. Write diagram source.
3. Keep it readable.
4. Render and check.
5. Store next to docs.

## Quality checklist
- [ ] Renders without errors
- [ ] labels clear

## Output
Diagram source and render.
