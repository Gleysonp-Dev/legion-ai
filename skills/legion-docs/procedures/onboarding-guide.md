# Onboarding Guide

> Legion procedure `onboarding-guide` · pack **Documentation** (`legion-docs`)

## When to use
Write a developer onboarding guide: setup, architecture tour, workflows, conventions and first tasks. Use when new people join a project.

## Procedure
1. List setup steps with commands.
2. Give an architecture tour.
3. Explain workflows (branches, reviews, deploys).
4. Link standards.
5. Suggest starter tasks.

## Quality checklist
- [ ] Setup verified on a fresh machine

ONBOARDING.md.
