# Readme Writer

> Legion procedure `readme-writer` · pack **Documentation** (`legion-docs`)

## When to use
Write a great README: what it is, why, install, quick start, usage, configuration, contributing and licence. Use for any project.

## Procedure
1. Explain what the project does in one sentence.
2. Show a quick start that works copy-paste.
3. Document configuration and common tasks.
4. Add badges, screenshots or GIFs where helpful.
5. Link to deeper docs, contributing and licence.

## Quality checklist
- [ ] Quick start tested
- [ ] one-sentence pitch

## Output
README.md.
