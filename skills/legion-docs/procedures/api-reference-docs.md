# API Reference Docs

> Legion procedure `api-reference-docs` · pack **Documentation** (`legion-docs`)

## When to use
Generate and polish API reference docs from code or OpenAPI specs. Use when developers need complete reference material.

## Procedure
1. Generate reference from source of truth.
2. Add descriptions and examples to each item.
3. Group logically.
4. Document errors and limits.
5. Publish and link from README.

## Quality checklist
- [ ] Every public item documented with example

## Output
API reference pages.
