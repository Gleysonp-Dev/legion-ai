# Customer Feedback Synthesis

> Legion skill · category **Product Management**

## When to use
Synthesise customer feedback from tickets, reviews and interviews into themes, counts and recommendations. Use to decide what to fix or build.

## Procedure
1. Collect feedback sources.
2. Code each item into themes.
3. Count and weight by customer value.
4. Quote representative examples.
5. Recommend actions.

## Quality checklist
- [ ] Themes quantified
- [ ] quotes included

## Output
Feedback synthesis.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
