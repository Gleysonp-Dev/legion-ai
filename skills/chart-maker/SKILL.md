# Chart Maker

> Legion skill · category **Data Analysis & Visualisation**

## When to use
Create a clear, honest chart from data with the right chart type, labels and a takeaway title. Use whenever data should be visualised.

## Procedure
1. Identify the message (trend, comparison, distribution, relationship).
2. Pick the matching chart type.
3. Label axes with units; start bar axes at zero.
4. Use colour to highlight the point.
5. Title the chart with the takeaway.

## Quality checklist
- [ ] Axes honest
- [ ] accessible colours
- [ ] takeaway title

## Output
Chart image or code.

## Works well with
Legion agents: `data-analyst`, `data-visualizer`, `analytics-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
