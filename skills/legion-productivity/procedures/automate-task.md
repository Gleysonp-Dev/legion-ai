# Automate Task

> Legion procedure `automate-task` · pack **Productivity & Automation** (`legion-productivity`)

## When to use
Automate a repetitive computer task with a script (Python, Node, Bash, PowerShell) that runs on Windows, Mac or Linux. Use when someone repeats the same steps often.

## Procedure
1. Document the manual steps and inputs.
2. Choose a language available on the user's machine.
3. Write the script with clear configuration and logging.
4. Add dry-run mode and error handling.
5. Test on samples and document usage.

## Quality checklist
- [ ] Dry-run available
- [ ] cross-platform paths

## Output
Script and usage notes.
