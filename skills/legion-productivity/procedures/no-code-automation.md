# No Code Automation

> Legion procedure `no-code-automation` · pack **Productivity & Automation** (`legion-productivity`)

## When to use
Design automations in Zapier, Make, n8n or Power Automate connecting apps with triggers, filters and error handling. Use for business workflows without code.

## Procedure
1. Map trigger and actions.
2. Choose platform.
3. Add filters and data mapping.
4. Add error notifications.
5. Test with real data.

## Quality checklist
- [ ] Error handling configured
- [ ] tested

## Output
Automation design and setup steps.
