# Android Kotlin

> Legion skill · category **Mobile Development**

## When to use
Build native Android features with Kotlin, Jetpack Compose, coroutines and Android architecture components. Use for native Android development.

## Procedure
1. Follow Material Design guidelines.
2. Use Compose with ViewModel and state hoisting.
3. Use coroutines and Flow for async work.
4. Handle lifecycle and configuration changes.
5. Test with JUnit and Compose tests.

Kotlin code and tests.
