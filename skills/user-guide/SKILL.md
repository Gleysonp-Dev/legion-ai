# User Guide

> Legion skill · category **Documentation**

## When to use
Write end-user help documentation and FAQs in plain language with screenshots placeholders. Use for product help centres.

## Procedure
1. List user tasks.
2. Write a short article per task.
3. Use plain language and numbered steps.
4. Add FAQs from support tickets.
5. Organise by user journey.

## Quality checklist
- [ ] Plain language
- [ ] task-oriented

## Output
Help articles.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
