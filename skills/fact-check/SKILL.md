# Fact Check

> Legion skill · category **Research & Analysis**

## When to use
Verify claims against reliable sources and rate them true, false, misleading or unverified. Use before publishing or deciding.

## Procedure
1. List each factual claim.
2. Find primary sources.
3. Compare and rate.
4. Note context.
5. Cite sources.

## Quality checklist
- [ ] Primary sources used
- [ ] ratings justified

## Output
Fact-check table.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
