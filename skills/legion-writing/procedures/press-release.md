# Press Release

> Legion procedure `press-release` · pack **Writing & Communication** (`legion-writing`)

## When to use
Write a press release with headline, dateline, lead, quotes, boilerplate and contact. Use for announcements.

## Procedure
1. Write a newsworthy headline.
2. Answer who, what, when, where, why in the lead.
3. Add quotes (marked as drafts for approval).
4. Add boilerplate and contact.
5. Keep to one page.

## Quality checklist
- [ ] Quotes marked for approval
- [ ] facts verified

## Output
Press release draft.
