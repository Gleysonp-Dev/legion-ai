# Newsletter

> Legion procedure `newsletter` · pack **Writing & Communication** (`legion-writing`)

## When to use
Write a newsletter issue with sections, curated links, commentary and a CTA. Use for regular audience updates.

## Procedure
1. Pick theme and highlights.
2. Write intro.
3. Add sections with commentary.
4. Add CTA.
5. Write subject line variants.

## Quality checklist
- [ ] Scannable
- [ ] one CTA

## Output
Newsletter draft.
