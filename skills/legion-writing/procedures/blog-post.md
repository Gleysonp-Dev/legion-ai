# Blog Post

> Legion procedure `blog-post` · pack **Writing & Communication** (`legion-writing`)

## When to use
Write a well-structured blog post with hook, clear sections, examples and SEO basics. Use for content marketing or thought leadership.

## Procedure
1. Define audience, angle and key takeaway.
2. Outline with headings.
3. Write a strong hook intro.
4. Use examples and data.
5. End with summary and CTA.

## Quality checklist
- [ ] One clear takeaway
- [ ] scannable headings

## Output
Blog post draft.
