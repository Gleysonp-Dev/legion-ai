# Translate Localize

> Legion skill · category **Writing & Communication**

## When to use
Translate and localise text between languages (e.g. Portuguese, English, Spanish) preserving tone, idioms and formatting. Use for multilingual content.

## Procedure
1. Identify audience and locale.
2. Translate meaning, not words.
3. Adapt idioms, units and formats.
4. Keep placeholders and markup intact.
5. Note ambiguous terms.

## Quality checklist
- [ ] Natural in target language
- [ ] formatting intact

## Output
Translation and notes.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
