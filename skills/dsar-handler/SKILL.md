# DSAR Handler

> Legion skill · category **Legal, Privacy & Compliance (not legal advice)**

## When to use
Build a process and tooling to handle data subject access, deletion and portability requests. Use for LGPD/GDPR obligations.

## Procedure
1. Define intake and identity verification.
2. Locate data across systems.
3. Export or delete.
4. Respond within deadlines.
5. Log requests.

## Quality checklist
- [ ] Identity verified
- [ ] deadlines tracked

## Output
DSAR process and scripts.

## Works well with
Legion agents: `legal-researcher`, `privacy-engineer`, `compliance-analyst`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
