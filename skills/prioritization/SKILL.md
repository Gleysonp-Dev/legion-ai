# Prioritization

> Legion skill · category **Product Management**

## When to use
Prioritise a backlog with RICE, ICE, MoSCoW or Kano and explain trade-offs. Use when there is more to do than time.

## Procedure
1. List items with estimates.
2. Choose a framework.
3. Score items.
4. Review for dependencies and strategy fit.
5. Publish ranked list with rationale.

## Quality checklist
- [ ] Scores explained
- [ ] dependencies respected

## Output
Ranked backlog.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
