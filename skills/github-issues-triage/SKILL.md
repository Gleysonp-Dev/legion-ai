# Github Issues Triage

> Legion skill · category **Git & Collaboration**

## When to use
Triage GitHub issues: label, deduplicate, prioritise, request info and close stale ones. Use for busy repositories.

## Procedure
1. Read new issues and label by type and area.
2. Find duplicates.
3. Ask for reproduction info when missing.
4. Prioritise by impact.
5. Close stale issues politely.

## Quality checklist
- [ ] Every issue labelled
- [ ] duplicates linked

## Output
Triage summary.

## Works well with
Legion agents: `release-manager`, `code-reviewer`, `devops-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
