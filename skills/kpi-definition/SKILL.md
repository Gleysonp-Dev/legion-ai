# KPI Definition

> Legion skill · category **Business & Finance**

## When to use
Define business KPIs with formulas, data sources, owners, targets and review cadence. Use to manage performance.

## Procedure
1. Link KPIs to goals.
2. Define formulas.
3. Identify sources.
4. Assign owners.
5. Set targets.

## Quality checklist
- [ ] Every KPI has formula and owner

## Output
KPI catalogue.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
