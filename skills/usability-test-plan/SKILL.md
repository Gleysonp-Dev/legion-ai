# Usability Test Plan

> Legion skill · category **UX, UI & Accessibility**

## When to use
Plan and run usability tests: tasks, script, recruitment, metrics and synthesis. Use to validate designs with users.

## Procedure
1. Define research questions.
2. Write realistic tasks.
3. Write a neutral script.
4. Define metrics (success, time, errors).
5. Synthesise findings into fixes.

## Quality checklist
- [ ] Tasks realistic
- [ ] script neutral

## Output
Test plan and findings template.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
