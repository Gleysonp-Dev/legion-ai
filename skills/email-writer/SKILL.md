# Email Writer

> Legion skill · category **Writing & Communication**

## When to use
Write clear professional emails: requests, follow-ups, updates, apologies and negotiations. Use for any important email.

## Procedure
1. Identify the goal and recipient.
2. Put the ask in the first lines.
3. Give context briefly.
4. Make next steps explicit.
5. Match tone to relationship.

## Quality checklist
- [ ] Ask is clear
- [ ] concise

## Output
Email draft.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
