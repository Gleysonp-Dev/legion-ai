# Onboarding Guide

> Legion skill · category **Documentation**

## When to use
Write a developer onboarding guide: setup, architecture tour, workflows, conventions and first tasks. Use when new people join a project.

## Procedure
1. List setup steps with commands.
2. Give an architecture tour.
3. Explain workflows (branches, reviews, deploys).
4. Link standards.
5. Suggest starter tasks.

## Quality checklist
- [ ] Setup verified on a fresh machine

## Output
ONBOARDING.md.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
