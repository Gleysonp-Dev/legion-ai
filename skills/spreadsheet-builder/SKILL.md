# Spreadsheet Builder

> Legion skill · category **Productivity & Automation**

## When to use
Build spreadsheets with clean structure, formulas, validation, conditional formatting and charts. Use for trackers, calculators and reports.

## Procedure
1. Define purpose and inputs.
2. Structure tabs (inputs, calculations, outputs).
3. Use formulas and named ranges.
4. Add validation and formatting.
5. Add charts and instructions.

## Quality checklist
- [ ] No hard-coded results
- [ ] inputs validated

## Output
Spreadsheet.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
