# Mobile Performance

> Legion skill · category **Mobile Development**

## When to use
Improve mobile app performance: startup, frame rate, memory, battery and app size. Use when apps feel slow or drain battery.

## Procedure
1. Measure startup, frame rate and memory on low-end devices.
2. Optimise lists and images.
3. Reduce work on the main thread.
4. Limit background tasks and location use.
5. Reduce app size.

## Quality checklist
- [ ] Measured on low-end device

## Output
Performance report and fixes.

## Works well with
Legion agents: `mobile-engineer`, `ui-designer`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
