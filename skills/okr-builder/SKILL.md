# OKR Builder

> Legion skill · category **Planning & Delivery**

## When to use
Draft OKRs (objectives and measurable key results) for a person, team or product. Use for quarterly goal-setting.

## Procedure
1. Write 1–3 inspiring, qualitative objectives tied to strategy.
2. Give each objective 2–4 measurable key results with baseline and target.
3. Ensure key results measure outcomes, not task completion.
4. List initiatives that could move each key result.
5. Define how and when progress will be scored.

## Quality checklist
- [ ] Every KR has a number and baseline
- [ ] outcomes not outputs

## Output
An OKR sheet with objectives, KRs, initiatives.

## Works well with
Legion agents: `conductor`, `task-splitter`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
