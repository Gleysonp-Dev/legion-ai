# User Stories

> Legion skill · category **Product Management**

## When to use
Write user stories with acceptance criteria (Given/When/Then) and split them to be small. Use for backlog creation.

## Procedure
1. Write stories as "As a…, I want…, so that…".
2. Add acceptance criteria.
3. Split large stories by workflow or data.
4. Check INVEST.
5. Order by value.

## Quality checklist
- [ ] Each story testable and small

## Output
Story list.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
