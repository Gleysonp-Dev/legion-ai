# Open Source Launch

> Legion skill · category **Git & Collaboration**

## When to use
Prepare a project for open-source release: licence, docs, contribution guide, code of conduct, issue labels and announcement. Use before publishing a project publicly.

## Procedure
1. Remove secrets and internal references.
2. Add licence, README, CONTRIBUTING and CODE_OF_CONDUCT.
3. Add good-first-issue labels and templates.
4. Set up CI and releases.
5. Draft a launch announcement.

## Quality checklist
- [ ] Secret scan clean
- [ ] contribution path clear

## Output
Launch checklist and files.

## Works well with
Legion agents: `release-manager`, `code-reviewer`, `devops-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
