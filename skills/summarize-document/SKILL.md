# Summarize Document

> Legion skill · category **Writing & Communication**

## When to use
Summarise long documents, reports, transcripts or threads into key points, decisions and action items. Use to digest content quickly.

## Procedure
1. Identify document type and reader need.
2. Extract main points.
3. List decisions and action items.
4. Keep important numbers.
5. Offer a one-line TL;DR.

## Quality checklist
- [ ] No invented facts
- [ ] numbers preserved

## Output
Summary.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
