# Pitch Deck

> Legion skill · category **Business & Finance**

## When to use
Create a startup pitch deck outline: problem, solution, market, traction, model, competition, team, ask. Use for fundraising.

## Procedure
1. Write narrative.
2. Draft slide headlines.
3. Add supporting data.
4. Design visuals.
5. Prepare Q&A.

## Quality checklist
- [ ] 10–15 slides
- [ ] clear ask

## Output
Pitch deck outline or file.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
