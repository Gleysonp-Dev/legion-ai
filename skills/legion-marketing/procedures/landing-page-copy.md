# Landing Page Copy

> Legion procedure `landing-page-copy` · pack **Marketing & Growth** (`legion-marketing`)

## When to use
Write conversion-focused landing page copy: headline, subhead, benefits, objections, proof and CTA. Use for product or campaign pages.

## Procedure
1. Identify audience pain and promise.
2. Write headline variants.
3. List benefits with proof.
4. Handle objections in FAQ.
5. Write CTA.

## Quality checklist
- [ ] Benefit-led
- [ ] one primary CTA

## Output
Landing page copy.
