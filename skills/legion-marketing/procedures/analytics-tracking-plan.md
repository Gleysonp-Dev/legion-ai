# Analytics Tracking Plan

> Legion procedure `analytics-tracking-plan` · pack **Marketing & Growth** (`legion-marketing`)

## When to use
Create a marketing analytics tracking plan with UTM conventions, events, conversions and attribution. Use before campaigns.

## Procedure
1. Define conversion events.
2. Define UTM naming conventions.
3. Map events to tools.
4. Configure attribution.
5. Verify tracking.

## Quality checklist
- [ ] UTM convention documented
- [ ] events verified

## Output
Tracking plan.
