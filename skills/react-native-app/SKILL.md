# React Native App

> Legion skill · category **Mobile Development**

## When to use
Build or extend a React Native / Expo app with navigation, state, native modules and builds. Use for cross-platform mobile apps in JavaScript/TypeScript.

## Procedure
1. Scaffold with Expo unless native requirements prevent it.
2. Set up navigation and typed routes.
3. Use the same data-fetching patterns as web where possible.
4. Handle permissions and platform differences.
5. Build with EAS and test on real devices.

## Quality checklist
- [ ] Works on iOS and Android
- [ ] permissions handled

## Output
App code and build config.

## Works well with
Legion agents: `mobile-engineer`, `ui-designer`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
