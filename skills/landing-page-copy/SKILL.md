# Landing Page Copy

> Legion skill · category **Marketing & Growth**

## When to use
Write conversion-focused landing page copy: headline, subhead, benefits, objections, proof and CTA. Use for product or campaign pages.

## Procedure
1. Identify audience pain and promise.
2. Write headline variants.
3. List benefits with proof.
4. Handle objections in FAQ.
5. Write CTA.

## Quality checklist
- [ ] Benefit-led
- [ ] one primary CTA

## Output
Landing page copy.

## Works well with
Legion agents: `growth-strategist`, `seo-specialist`, `social-media-manager`, `content-strategist`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
