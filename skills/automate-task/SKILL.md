# Automate Task

> Legion skill · category **Productivity & Automation**

## When to use
Automate a repetitive computer task with a script (Python, Node, Bash, PowerShell) that runs on Windows, Mac or Linux. Use when someone repeats the same steps often.

## Procedure
1. Document the manual steps and inputs.
2. Choose a language available on the user's machine.
3. Write the script with clear configuration and logging.
4. Add dry-run mode and error handling.
5. Test on samples and document usage.

## Quality checklist
- [ ] Dry-run available
- [ ] cross-platform paths

## Output
Script and usage notes.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
