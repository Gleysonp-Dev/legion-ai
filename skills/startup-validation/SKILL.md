# Startup Validation

> Legion skill · category **Business & Finance**

## When to use
Validate a startup idea quickly: problem interviews, landing page tests, pre-sales and success criteria. Use before building.

## Procedure
1. Define hypotheses.
2. Design cheap tests.
3. Set success thresholds.
4. Run and collect evidence.
5. Decide go, pivot or stop.

## Quality checklist
- [ ] Thresholds set before testing

## Output
Validation plan and results.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
