# Computer Vision

> Legion skill · category **Machine Learning**

## When to use
Build computer vision solutions: classification, detection, OCR with pretrained models and fine-tuning. Use for image or video tasks.

## Procedure
1. Define task and label format.
2. Start from a pretrained model.
3. Prepare and augment data.
4. Fine-tune and evaluate.
5. Optimise for deployment target.

## Quality checklist
- [ ] Evaluated on realistic images

## Output
Model and evaluation.

## Works well with
Legion agents: `ml-engineer`, `data-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
