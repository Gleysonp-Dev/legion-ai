# Tutorial Writer

> Legion skill · category **Documentation**

## When to use
Write step-by-step tutorials that take a beginner from zero to a working result. Use for onboarding users or developers.

## Procedure
1. Define the end result and prerequisites.
2. Write numbered steps with commands and expected output.
3. Explain the why briefly at each step.
4. Test the tutorial from scratch.
5. End with next steps.

## Quality checklist
- [ ] Tested from clean environment

## Output
Tutorial document.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
