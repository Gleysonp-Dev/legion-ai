# Repo Setup

> Legion skill · category **Git & Collaboration**

## When to use
Set up a professional GitHub repository: README, licence, .gitignore, templates, CI, branch protection and topics. Use when creating or publishing a project.

## Procedure
1. Add README with badges, install and usage.
2. Choose licence.
3. Add .gitignore, issue/PR templates and CONTRIBUTING.
4. Add CI workflow.
5. Configure description, topics and branch protection.

## Quality checklist
- [ ] README has install instructions
- [ ] licence present

## Output
Repo files and settings checklist.

## Works well with
Legion agents: `release-manager`, `code-reviewer`, `devops-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
