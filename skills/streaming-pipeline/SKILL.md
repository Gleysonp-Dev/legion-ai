# Streaming Pipeline

> Legion skill · category **Data Engineering**

## When to use
Build streaming pipelines with Kafka, Kinesis, Pub/Sub or Flink: topics, consumers, windows and exactly-once concerns. Use for real-time data.

## Procedure
1. Define events, keys and partitions.
2. Choose processing framework.
3. Handle late data with windows and watermarks.
4. Make consumers idempotent.
5. Monitor lag.

## Quality checklist
- [ ] Consumer lag monitored
- [ ] idempotency ensured

## Output
Streaming pipeline design and code.

## Works well with
Legion agents: `data-engineer`, `analytics-engineer`, `database-architect`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
