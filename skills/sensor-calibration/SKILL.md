# Sensor Calibration

> Legion skill · category **IoT & Embedded**

## When to use
Calibrate sensors (pH, temperature, ORP, chlorine, flow, pressure) with reference points, drift tracking and filtering. Use for accurate measurements.

## Procedure
1. Identify sensor characteristics.
2. Collect reference measurements.
3. Fit calibration curve.
4. Add filtering.
5. Schedule recalibration.

## Quality checklist
- [ ] Calibration error quantified

Calibration procedure and code.
