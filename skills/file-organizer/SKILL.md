# File Organizer

> Legion skill · category **Productivity & Automation**

## When to use
Organise files and folders: rename in bulk, sort by type or date, deduplicate and archive. Use to clean up messy folders.

## Procedure
1. Inventory the folder.
2. Propose an organisation scheme.
3. Preview changes before applying.
4. Apply with collision-safe moves.
5. Report what changed.

## Quality checklist
- [ ] Preview before change
- [ ] nothing deleted without approval

## Output
Organisation plan and change log.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
