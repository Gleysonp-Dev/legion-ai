# Launch Plan

> Legion skill · category **Product Management**

## When to use
Plan a product or feature launch: readiness checklist, messaging, channels, timeline and success metrics. Use before going live.

## Procedure
1. Define audience and message.
2. Build readiness checklist.
3. Plan channels and assets.
4. Create timeline.
5. Define launch metrics.

## Quality checklist
- [ ] Readiness owners assigned
- [ ] metrics defined

## Output
Launch plan.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
