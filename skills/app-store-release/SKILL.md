# App Store Release

> Legion skill · category **Mobile Development**

## When to use
Prepare App Store and Google Play releases: metadata, screenshots, privacy labels, review guidelines and staged rollout. Use before publishing a mobile app.

## Procedure
1. Check review guidelines for risky features.
2. Prepare metadata, keywords and screenshots.
3. Complete privacy and data safety forms accurately.
4. Build signed release versions.
5. Use staged rollout and monitor crashes.

## Quality checklist
- [ ] Privacy forms match actual data use
- [ ] staged rollout

## Output
Release checklist and assets list.

## Works well with
Legion agents: `mobile-engineer`, `ui-designer`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
