# Release Automation

> Legion skill · category **DevOps & CI/CD**

## When to use
Automate versioning, changelogs and releases (semantic-release, changesets, release-please). Use to stop manual release chores.

## Procedure
1. Adopt conventional commits or changesets.
2. Configure the release tool for the repo type.
3. Generate changelogs and GitHub releases.
4. Publish packages or artifacts automatically.
5. Protect release workflow permissions.

## Quality checklist
- [ ] Versions follow semver
- [ ] changelog generated

## Output
Release configuration.

## Works well with
Legion agents: `devops-engineer`, `ci-cd-engineer`, `container-specialist`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
