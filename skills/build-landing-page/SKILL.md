# Build Landing Page

> Legion skill · category **Frontend Development**

## When to use
Build a responsive, fast landing page with hero, benefits, social proof, pricing and CTA. Use for product launches and marketing sites.

## Procedure
1. Define the audience, offer and single call to action.
2. Structure sections: hero, problem, solution, benefits, proof, pricing, FAQ, CTA.
3. Implement mobile-first with semantic HTML and accessible contrast.
4. Optimise images and fonts for fast load.
5. Add analytics events on CTAs.

## Quality checklist
- [ ] Works at 360px
- [ ] Lighthouse performance and accessibility ≥ 90
- [ ] one clear CTA

## Output
Landing page code ready to deploy.

## Works well with
Legion agents: `ui-engineer`, `react-specialist`, `css-stylist`, `frontend-architect`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
