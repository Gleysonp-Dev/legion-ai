# Pricing Strategy

> Legion skill · category **Business & Finance**

## When to use
Design pricing: value metrics, tiers, price points, discounting and experiments. Use for SaaS or product pricing decisions.

## Procedure
1. Identify value metric.
2. Research competitor and willingness-to-pay.
3. Design tiers.
4. Set price points.
5. Plan experiments.

## Quality checklist
- [ ] Value metric aligned with customer value

## Output
Pricing proposal.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
