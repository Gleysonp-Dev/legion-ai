# Diagram As Code

> Legion skill · category **Documentation**

## When to use
Create diagrams as code with Mermaid, PlantUML or D2: flowcharts, sequence, ER, state and architecture diagrams. Use to explain flows visually.

## Procedure
1. Choose diagram type for the question.
2. Write diagram source.
3. Keep it readable.
4. Render and check.
5. Store next to docs.

## Quality checklist
- [ ] Renders without errors
- [ ] labels clear

## Output
Diagram source and render.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
