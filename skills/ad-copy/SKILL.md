# Ad Copy

> Legion skill · category **Marketing & Growth**

## When to use
Write ad copy for Google, Meta, LinkedIn and TikTok within platform limits, with variants for testing. Use for paid campaigns.

## Procedure
1. Define audience, offer and objective.
2. Respect character limits.
3. Write multiple headline and description variants.
4. Match landing page message.
5. Plan tests.

## Quality checklist
- [ ] Within limits
- [ ] variants differ meaningfully

## Output
Ad copy sets.

## Works well with
Legion agents: `growth-strategist`, `seo-specialist`, `social-media-manager`, `content-strategist`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
