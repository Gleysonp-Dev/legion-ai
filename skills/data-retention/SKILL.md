# Data Retention

> Legion skill · category **Legal, Privacy & Compliance (not legal advice)**

## When to use
Define and implement data retention and deletion schedules. Use to reduce risk and comply with regulations.

## Procedure
1. Inventory data types.
2. Set retention periods with reasons.
3. Implement automated deletion.
4. Handle backups.
5. Document schedule.

## Quality checklist
- [ ] Automated deletion in place

## Output
Retention schedule and jobs.

## Works well with
Legion agents: `legal-researcher`, `privacy-engineer`, `compliance-analyst`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
