# Branching Strategy

> Legion skill · category **Git & Collaboration**

## When to use
Choose and document a branching strategy (trunk-based, GitHub flow, release branches) with protection rules. Use to organise team git workflow.

## Procedure
1. Assess team size and release cadence.
2. Recommend a strategy.
3. Define branch naming and protections.
4. Define merge method.
5. Document the workflow.

## Quality checklist
- [ ] Protections defined
- [ ] strategy fits release cadence

## Output
Branching guide.

## Works well with
Legion agents: `release-manager`, `code-reviewer`, `devops-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
