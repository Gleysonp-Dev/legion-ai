# Roadmap Builder

> Legion skill · category **Product Management**

## When to use
Build a Now/Next/Later roadmap with themes, outcomes and dependencies. Use for planning communication.

## Procedure
1. Group initiatives into themes.
2. State outcome per theme.
3. Sequence by value and dependency.
4. Mark confidence levels.
5. Tailor views for audiences.

## Quality checklist
- [ ] Outcome-focused
- [ ] confidence marked

## Output
Roadmap document.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
