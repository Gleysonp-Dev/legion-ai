# Microcopy

> Legion skill · category **UX, UI & Accessibility**

## When to use
Write UI microcopy: buttons, labels, errors, empty states, tooltips and confirmations. Use to make interfaces clearer.

## Procedure
1. Use verbs on buttons that describe the outcome.
2. Write errors that say what happened and how to fix it.
3. Make empty states helpful with a next action.
4. Keep tone consistent with brand.
5. Cut words.

## Quality checklist
- [ ] Errors actionable
- [ ] consistent tone

## Output
Microcopy table.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
