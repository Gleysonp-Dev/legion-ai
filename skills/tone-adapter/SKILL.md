# Tone Adapter

> Legion skill · category **Writing & Communication**

## When to use
Adapt a text to a different tone or audience (formal, casual, technical, executive, friendly) without changing facts. Use when the same message must reach different readers.

## Procedure
1. Identify target audience and tone.
2. Adjust vocabulary and sentence length.
3. Adjust detail level.
4. Keep facts identical.
5. Show side-by-side if useful.

## Quality checklist
- [ ] Facts unchanged
- [ ] tone consistent

## Output
Adapted text.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
