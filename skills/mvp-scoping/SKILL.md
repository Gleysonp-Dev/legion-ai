# MVP Scoping

> Legion skill · category **Product Management**

## When to use
Cut a product idea down to a minimum viable product that tests the riskiest assumption. Use before building a new product.

## Procedure
1. List assumptions.
2. Identify riskiest assumption.
3. Design the smallest product or experiment to test it.
4. Define success criteria.
5. List what is deliberately excluded.

## Quality checklist
- [ ] Tests riskiest assumption
- [ ] exclusions explicit

## Output
MVP definition.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
