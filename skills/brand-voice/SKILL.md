# Brand Voice

> Legion skill · category **Marketing & Growth**

## When to use
Define a brand voice and tone guide with traits, do/don't examples and vocabulary. Use to keep communication consistent.

## Procedure
1. Define brand personality traits.
2. Describe tone per context.
3. Give do/don't examples.
4. List vocabulary.
5. Provide sample rewrites.

## Quality checklist
- [ ] Examples concrete
- [ ] contexts covered

## Output
Brand voice guide.

## Works well with
Legion agents: `growth-strategist`, `seo-specialist`, `social-media-manager`, `content-strategist`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
