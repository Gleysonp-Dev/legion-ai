# Technology Comparison

> Legion skill · category **Research & Analysis**

## When to use
Compare technologies, tools or vendors on features, performance, cost, maturity and fit with sources. Use for tool selection.

## Procedure
1. Define criteria.
2. Gather data from docs and benchmarks.
3. Build comparison table.
4. Test critical claims if possible.
5. Recommend with context.

## Quality checklist
- [ ] Sources dated
- [ ] criteria weighted

## Output
Comparison table and recommendation.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
