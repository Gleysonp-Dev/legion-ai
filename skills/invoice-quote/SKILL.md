# Invoice Quote

> Legion skill · category **Business & Finance**

## When to use
Create professional quotes, proposals and invoice templates with clear scope, terms and totals. Use for freelancers and small businesses.

## Procedure
1. Define scope and deliverables.
2. List items with quantities and prices.
3. Add taxes and totals.
4. Add payment terms.
5. Format professionally.

## Quality checklist
- [ ] Totals correct
- [ ] terms clear

## Output
Quote or invoice template.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
