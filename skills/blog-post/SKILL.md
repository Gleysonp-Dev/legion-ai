# Blog Post

> Legion skill · category **Writing & Communication**

## When to use
Write a well-structured blog post with hook, clear sections, examples and SEO basics. Use for content marketing or thought leadership.

## Procedure
1. Define audience, angle and key takeaway.
2. Outline with headings.
3. Write a strong hook intro.
4. Use examples and data.
5. End with summary and CTA.

## Quality checklist
- [ ] One clear takeaway
- [ ] scannable headings

## Output
Blog post draft.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
