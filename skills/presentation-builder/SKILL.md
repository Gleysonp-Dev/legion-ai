# Presentation Builder

> Legion skill · category **Productivity & Automation**

## When to use
Create presentation slides with storyline, headlines, visuals and speaker notes. Use for meetings, talks and pitches.

## Procedure
1. Define audience and message.
2. Outline storyline.
3. Write headline per slide.
4. Add visuals and data.
5. Write speaker notes.

## Quality checklist
- [ ] One idea per slide
- [ ] headlines state the point

## Output
Slide deck or outline.

## Works well with
Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
