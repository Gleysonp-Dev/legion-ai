# Flutter App

> Legion procedure `flutter-app` · pack **Mobile Development** (`legion-mobile`)

## When to use
Build Flutter apps with widgets, state management, theming and platform channels. Use for Flutter/Dart projects.

## Procedure
1. Structure features into folders with clear layers.
2. Choose state management (Riverpod, Bloc) consistently.
3. Build responsive layouts and theming.
4. Use platform channels only when needed.
5. Test widgets and integration flows.

## Quality checklist
- [ ] Widget tests pass
- [ ] consistent state management

## Output
Flutter code and tests.
