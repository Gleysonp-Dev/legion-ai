# iOS SwiftUI

> Legion procedure `ios-swiftui` · pack **Mobile Development** (`legion-mobile`)

## When to use
Build native iOS features with SwiftUI, async/await, Combine and Apple frameworks. Use for native iPhone/iPad development.

## Procedure
1. Follow Human Interface Guidelines.
2. Structure with MVVM and observable models.
3. Use async/await for networking.
4. Support Dynamic Type, dark mode and accessibility.
5. Test with XCTest and previews.

## Quality checklist
- [ ] Accessibility and dark mode supported

## Output
Swift code and tests.
