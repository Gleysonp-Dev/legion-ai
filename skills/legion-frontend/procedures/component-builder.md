# Component Builder

> Legion procedure `component-builder` · pack **Frontend Development** (`legion-frontend`)

## When to use
Create a reusable UI component with props API, variants, states, accessibility and tests. Use when adding buttons, modals, tables, dropdowns or any shared widget.

## Procedure
1. Define the props API and variants before coding.
2. Implement all states: default, hover, focus, active, disabled, loading, error.
3. Add keyboard support and correct ARIA roles.
4. Write usage examples and unit tests.
5. Keep styling consistent with design tokens.

## Quality checklist
- [ ] Keyboard operable
- [ ] all states covered
- [ ] tests pass

## Output
Component file, tests and usage example.
