# Form Builder

> Legion procedure `form-builder` · pack **Frontend Development** (`legion-frontend`)

## When to use
Build robust forms with validation, error messages, accessibility and submission handling. Use for signup, checkout, settings or any data entry.

## Procedure
1. Define fields, types, required rules and validation constraints.
2. Use labels, helpful placeholders and input types for mobile keyboards.
3. Validate on blur and submit; show clear, specific error messages.
4. Handle submission states: loading, success, server errors, retries.
5. Validate again on the server; never trust the client.

## Quality checklist
- [ ] Every input labelled
- [ ] errors announced
- [ ] double-submit prevented

## Output
Form code with client and server validation.
