# Tailwind Setup

> Legion procedure `tailwind-setup` · pack **Frontend Development** (`legion-frontend`)

## When to use
Set up or refactor Tailwind CSS with design tokens, theme config, component patterns and class organisation. Use for Tailwind projects or migrations to Tailwind.

## Procedure
1. Install and configure Tailwind for the framework in use.
2. Map brand tokens into the theme config.
3. Extract repeated class groups into components, not @apply everywhere.
4. Enable dark mode and container queries if needed.
5. Add the Prettier plugin for class sorting.

## Quality checklist
- [ ] Tokens centralised
- [ ] no unused CSS in build
- [ ] consistent class order

## Output
Tailwind config and refactored components.
