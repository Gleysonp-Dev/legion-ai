# Github Issues Triage

> Legion procedure `github-issues-triage` · pack **Git & Collaboration** (`legion-git`)

## When to use
Triage GitHub issues: label, deduplicate, prioritise, request info and close stale ones. Use for busy repositories.

## Procedure
1. Read new issues and label by type and area.
2. Find duplicates.
3. Ask for reproduction info when missing.
4. Prioritise by impact.
5. Close stale issues politely.

## Quality checklist
- [ ] Every issue labelled
- [ ] duplicates linked

## Output
Triage summary.
