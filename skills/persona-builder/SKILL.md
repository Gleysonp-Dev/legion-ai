# Persona Builder

> Legion skill · category **UX, UI & Accessibility**

## When to use
Create evidence-based personas or jobs-to-be-done profiles from research data. Use to align a team on who the user is.

## Procedure
1. Gather research data.
2. Cluster users by goals and behaviours.
3. Write personas with goals, pains and context.
4. Mark assumptions.
5. Use JTBD statements.

## Quality checklist
- [ ] Based on evidence
- [ ] assumptions marked

## Output
Persona profiles.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
