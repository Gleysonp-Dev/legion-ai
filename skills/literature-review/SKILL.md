# Literature Review

> Legion skill · category **Research & Analysis**

## When to use
Review academic or technical literature: search, screen, summarise and synthesise findings. Use for research projects.

## Procedure
1. Define scope and search terms.
2. Search databases (Google Scholar, arXiv, PubMed).
3. Screen for relevance and quality.
4. Summarise each source.
5. Synthesise themes and gaps.

## Quality checklist
- [ ] Search terms documented
- [ ] quality assessed

## Output
Literature review.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
