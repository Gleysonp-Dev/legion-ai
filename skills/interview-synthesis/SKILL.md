# Interview Synthesis

> Legion skill · category **Research & Analysis**

## When to use
Synthesise interview notes or transcripts into themes, quotes and insights. Use after customer or expert interviews.

## Procedure
1. Tag notes by topic.
2. Cluster into themes.
3. Count frequency.
4. Select quotes.
5. Derive insights.

## Quality checklist
- [ ] Quotes attributed anonymously
- [ ] themes counted

## Output
Synthesis report.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
