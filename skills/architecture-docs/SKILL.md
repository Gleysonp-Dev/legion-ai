# Architecture Docs

> Legion skill · category **Documentation**

## When to use
Document system architecture for developers: overview, components, data flow, decisions and operations. Use for onboarding and knowledge sharing.

## Procedure
1. Write a one-page overview.
2. Add diagrams for context and containers.
3. Describe components and responsibilities.
4. Link ADRs.
5. Describe how to run, deploy and debug.

## Quality checklist
- [ ] New developer can find their way

## Output
docs/architecture.md.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
