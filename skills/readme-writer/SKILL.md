# Readme Writer

> Legion skill · category **Documentation**

## When to use
Write a great README: what it is, why, install, quick start, usage, configuration, contributing and licence. Use for any project.

## Procedure
1. Explain what the project does in one sentence.
2. Show a quick start that works copy-paste.
3. Document configuration and common tasks.
4. Add badges, screenshots or GIFs where helpful.
5. Link to deeper docs, contributing and licence.

## Quality checklist
- [ ] Quick start tested
- [ ] one-sentence pitch

## Output
README.md.

## Works well with
Legion agents: `technical-writer`, `documentation-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
