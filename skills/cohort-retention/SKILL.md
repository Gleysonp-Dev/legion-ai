# Cohort Retention

> Legion skill · category **Data Analysis & Visualisation**

## When to use
Build cohort and retention analyses to see how user behaviour changes over time. Use for product engagement and churn questions.

## Procedure
1. Define cohort (signup month) and activity event.
2. Compute retention by period.
3. Visualise as a heatmap or curves.
4. Compare cohorts for trends.
5. Explain drivers with segment cuts.

## Quality checklist
- [ ] Definitions explicit
- [ ] partial periods excluded

## Output
Cohort table, chart and insights.

Legion agents: `data-analyst`, `data-visualizer`, `analytics-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
