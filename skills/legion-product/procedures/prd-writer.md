# PRD Writer

> Legion procedure `prd-writer` · pack **Product Management** (`legion-product`)

## When to use
Write a product requirements document: problem, goals, users, stories, scope, metrics and open questions. Use when defining a feature.

## Procedure
1. Describe problem and evidence.
2. Set goals and non-goals.
3. Write user stories with acceptance criteria.
4. Define success metrics.
5. List risks and open questions.

## Quality checklist
- [ ] Non-goals explicit
- [ ] metrics measurable

## Output
PRD document.
