# Roadmap Builder

> Legion procedure `roadmap-builder` · pack **Product Management** (`legion-product`)

## When to use
Build a Now/Next/Later roadmap with themes, outcomes and dependencies. Use for planning communication.

## Procedure
1. Group initiatives into themes.
2. State outcome per theme.
3. Sequence by value and dependency.
4. Mark confidence levels.
5. Tailor views for audiences.

## Quality checklist
- [ ] Outcome-focused
- [ ] confidence marked

## Output
Roadmap document.
