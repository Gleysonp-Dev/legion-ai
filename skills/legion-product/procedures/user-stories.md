# User Stories

> Legion procedure `user-stories` · pack **Product Management** (`legion-product`)

## When to use
Write user stories with acceptance criteria (Given/When/Then) and split them to be small. Use for backlog creation.

## Procedure
1. Write stories as "As a…, I want…, so that…".
2. Add acceptance criteria.
3. Split large stories by workflow or data.
4. Check INVEST.
5. Order by value.

## Quality checklist
- [ ] Each story testable and small

## Output
Story list.
