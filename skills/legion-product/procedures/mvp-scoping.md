# MVP Scoping

> Legion procedure `mvp-scoping` · pack **Product Management** (`legion-product`)

## When to use
Cut a product idea down to a minimum viable product that tests the riskiest assumption. Use before building a new product.

## Procedure
1. List assumptions.
2. Identify riskiest assumption.
3. Design the smallest product or experiment to test it.
4. Define success criteria.
5. List what is deliberately excluded.

## Quality checklist
- [ ] Tests riskiest assumption
- [ ] exclusions explicit

## Output
MVP definition.
