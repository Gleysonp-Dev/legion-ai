# Product Metrics

> Legion procedure `product-metrics` · pack **Product Management** (`legion-product`)

## When to use
Define product metrics: north star, input metrics, guardrails and instrumentation. Use to measure product success.

## Procedure
1. Define the north star metric.
2. Map input metrics.
3. Add guardrails.
4. Specify tracking.
5. Set targets.

## Quality checklist
- [ ] Metrics actionable and instrumented

## Output
Metrics framework.
