# Launch Plan

> Legion procedure `launch-plan` · pack **Product Management** (`legion-product`)

## When to use
Plan a product or feature launch: readiness checklist, messaging, channels, timeline and success metrics. Use before going live.

## Procedure
1. Define audience and message.
2. Build readiness checklist.
3. Plan channels and assets.
4. Create timeline.
5. Define launch metrics.

## Quality checklist
- [ ] Readiness owners assigned
- [ ] metrics defined

## Output
Launch plan.
