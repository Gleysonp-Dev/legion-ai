# Usability Heuristics

> Legion procedure `usability-heuristics` · pack **UX, UI & Accessibility** (`legion-ux-design`)

## When to use
Evaluate an interface against Nielsen's 10 usability heuristics and propose fixes. Use for quick UX reviews.

## Procedure
1. Walk through main tasks.
2. Check each heuristic.
3. Rate severity of each issue.
4. Propose fixes.
5. Prioritise.

## Quality checklist
- [ ] Issues tied to heuristics and tasks

## Output
Heuristic evaluation table.
