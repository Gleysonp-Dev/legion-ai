# Design Tokens

> Legion procedure `design-tokens` · pack **UX, UI & Accessibility** (`legion-ux-design`)

## When to use
Define design tokens (colour, type, spacing, radius, shadow, motion) and export them to CSS/Tailwind/JSON. Use to create a consistent design foundation.

## Procedure
1. Define primitive values.
2. Create semantic tokens mapped to primitives.
3. Provide light and dark themes.
4. Export to platform formats.
5. Document usage.

## Quality checklist
- [ ] Semantic layer exists
- [ ] themes complete

## Output
Token files and docs.
