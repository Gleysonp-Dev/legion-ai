# UI Polish

> Legion procedure `ui-polish` · pack **UX, UI & Accessibility** (`legion-ux-design`)

## When to use
Improve the visual quality of an interface: hierarchy, spacing, typography, colour and consistency. Use when a UI looks amateur.

## Procedure
1. Audit hierarchy: what should be noticed first.
2. Apply a spacing scale consistently.
3. Limit to 2 type families and a clear scale.
4. Use a restrained palette with one accent.
5. Align elements to a grid.

## Quality checklist
- [ ] Consistent spacing
- [ ] contrast passes

## Output
Style changes with before/after notes.
