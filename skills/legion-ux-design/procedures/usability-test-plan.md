# Usability Test Plan

> Legion procedure `usability-test-plan` · pack **UX, UI & Accessibility** (`legion-ux-design`)

## When to use
Plan and run usability tests: tasks, script, recruitment, metrics and synthesis. Use to validate designs with users.

## Procedure
1. Define research questions.
2. Write realistic tasks.
3. Write a neutral script.
4. Define metrics (success, time, errors).
5. Synthesise findings into fixes.

## Quality checklist
- [ ] Tasks realistic
- [ ] script neutral

## Output
Test plan and findings template.
