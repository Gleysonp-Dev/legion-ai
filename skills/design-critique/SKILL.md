# Design Critique

> Legion skill · category **UX, UI & Accessibility**

## When to use
Critique a design or screenshot constructively: goals, hierarchy, clarity, consistency, accessibility. Use for feedback on mockups.

## Procedure
1. Clarify the design's goal.
2. Assess hierarchy and clarity.
3. Check consistency and accessibility.
4. Note strengths.
5. Give prioritised suggestions.

## Quality checklist
- [ ] Feedback tied to goals
- [ ] prioritised

## Output
Critique notes.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
