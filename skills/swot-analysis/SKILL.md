# SWOT Analysis

> Legion skill · category **Research & Analysis**

## When to use
Build a SWOT analysis with evidence and turn it into strategic actions. Use for strategy planning.

## Procedure
1. List internal strengths and weaknesses.
2. List external opportunities and threats.
3. Support each with evidence.
4. Derive SO/WO/ST/WT strategies.
5. Prioritise actions.

## Quality checklist
- [ ] Evidence-based
- [ ] actions derived

## Output
SWOT and actions.

## Works well with
Legion agents: `research-analyst`, `market-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
