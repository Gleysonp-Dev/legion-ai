# ML Experiment Tracking

> Legion procedure `ml-experiment-tracking` · pack **Machine Learning** (`legion-ml`)

## When to use
Set up experiment tracking (MLflow, Weights & Biases) for parameters, metrics, artifacts and data versions. Use when experiments are hard to compare.

## Procedure
1. Choose a tracking tool.
2. Log parameters, metrics, code version and data version.
3. Save artifacts and models.
4. Compare runs in the UI.
5. Document the workflow.

## Quality checklist
- [ ] Every run reproducible

## Output
Tracking setup.
