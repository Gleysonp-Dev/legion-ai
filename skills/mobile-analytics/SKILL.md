# Mobile Analytics

> Legion skill · category **Mobile Development**

## When to use
Instrument mobile analytics and crash reporting with privacy-respecting event tracking. Use to understand app usage.

## Procedure
1. Define a tracking plan.
2. Integrate analytics and crash SDKs.
3. Respect consent and platform tracking rules.
4. Verify events in debug mode.
5. Build key dashboards.

## Quality checklist
- [ ] Consent respected
- [ ] events verified

## Output
Analytics setup and tracking plan.

Legion agents: `mobile-engineer`, `ui-designer`, `release-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
