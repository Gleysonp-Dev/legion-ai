# Survey Analysis

> Legion skill · category **Data Analysis & Visualisation**

## When to use
Analyse survey results: response rates, Likert scales, cross-tabs, open-text themes and bias. Use after collecting survey data.

## Procedure
1. Report response rate and respondent profile.
2. Summarise closed questions with counts and percentages.
3. Cross-tab by key segments.
4. Code open-text answers into themes.
5. Note biases and limits.

## Quality checklist
- [ ] Sample size stated
- [ ] bias discussed

## Output
Survey report.

## Works well with
Legion agents: `data-analyst`, `data-visualizer`, `analytics-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
