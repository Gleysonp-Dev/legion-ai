# CSV Excel Processing

> Legion skill · category **Data Engineering**

## When to use
Process CSV and Excel files with pandas or similar: merge, filter, pivot, reshape and export. Use for file-based data work.

## Procedure
1. Load files with explicit types and encodings.
2. Validate columns and row counts.
3. Apply transformations step by step.
4. Export with correct formats.
5. Print a summary of changes.

## Quality checklist
- [ ] Encodings handled
- [ ] totals reconciled

## Output
Processed files and script.
