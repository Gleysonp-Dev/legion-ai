# Speech Script

> Legion skill · category **Writing & Communication**

## When to use
Write speeches, talk scripts or video scripts with structure, timing and delivery cues. Use for presentations or videos.

## Procedure
1. Define audience, length and goal.
2. Structure: hook, story, points, close.
3. Write for the ear: short sentences.
4. Add timing marks.
5. Add delivery cues.

## Quality checklist
- [ ] Fits time
- [ ] spoken-friendly

## Output
Script.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
