# Shell Scripting

> Legion skill · category **Productivity & Automation**

## When to use
Write robust shell scripts (Bash, PowerShell) with argument parsing, error handling, logging and portability. Use for command-line automation.

## Procedure
1. Choose shell for target OS.
2. Enable strict mode.
3. Parse arguments with help text.
4. Handle errors and cleanup.
5. Test on target systems.

## Quality checklist
- [ ] Strict mode
- [ ] help text
- [ ] quoting correct

## Output
Script.

Legion agents: `operations-automator`, `presentation-designer`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
