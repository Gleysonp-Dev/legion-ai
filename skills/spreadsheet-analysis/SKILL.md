# Spreadsheet Analysis

> Legion skill · category **Data Analysis & Visualisation**

## When to use
Analyse data in spreadsheets with formulas, pivot tables and charts. Use for Excel or Google Sheets analysis.

## Procedure
1. Clean and structure data as a table.
2. Use formulas for calculated columns.
3. Build pivot tables for summaries.
4. Add charts for key findings.
5. Document assumptions in a notes tab.

## Quality checklist
- [ ] Formulas, not hard-coded results
- [ ] notes included

## Output
Analysed spreadsheet.

## Works well with
Legion agents: `data-analyst`, `data-visualizer`, `analytics-engineer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
