# PRD Writer

> Legion skill · category **Product Management**

## When to use
Write a product requirements document: problem, goals, users, stories, scope, metrics and open questions. Use when defining a feature.

## Procedure
1. Describe problem and evidence.
2. Set goals and non-goals.
3. Write user stories with acceptance criteria.
4. Define success metrics.
5. List risks and open questions.

## Quality checklist
- [ ] Non-goals explicit
- [ ] metrics measurable

## Output
PRD document.

## Works well with
Legion agents: `product-manager`, `requirements-analyst`, `roadmap-planner`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
