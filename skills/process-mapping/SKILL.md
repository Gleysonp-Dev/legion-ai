# Process Mapping

> Legion skill · category **Business & Finance**

## When to use
Map business processes (as-is and to-be) with swimlanes, bottlenecks and improvements. Use for operational improvement.

## Procedure
1. Interview or read documentation.
2. Map as-is steps and owners.
3. Identify bottlenecks.
4. Design to-be.
5. Quantify improvement.

## Quality checklist
- [ ] Owners per step
- [ ] bottlenecks quantified

## Output
Process maps.

## Works well with
Legion agents: `business-analyst`, `financial-analyst`, `project-manager`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
