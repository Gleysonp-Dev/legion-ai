# Wireframe

> Legion skill · category **UX, UI & Accessibility**

## When to use
Create low-fidelity wireframes (ASCII, Mermaid or simple HTML) for key screens with annotations. Use to agree layout before visual design.

## Procedure
1. List content and actions per screen.
2. Prioritise by importance.
3. Sketch layout blocks.
4. Annotate interactions and states.
5. Iterate with feedback.

## Quality checklist
- [ ] Primary action obvious
- [ ] states annotated

## Output
Wireframes with notes.

## Works well with
Legion agents: `ux-designer`, `ui-designer`, `accessibility-expert`, `design-system-builder`, `ux-researcher`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
