# Security Questionnaire

> Legion skill · category **Legal, Privacy & Compliance (not legal advice)**

## When to use
Answer customer security questionnaires accurately from existing policies and evidence. Use in enterprise sales.

## Procedure
1. Collect policies and evidence.
2. Answer each question accurately.
3. Mark gaps honestly.
4. Reuse an answer library.
5. Review before sending.

## Quality checklist
- [ ] No overstated claims

## Output
Completed questionnaire.

## Works well with
Legion agents: `legal-researcher`, `privacy-engineer`, `compliance-analyst`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
