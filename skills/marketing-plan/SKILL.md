# Marketing Plan

> Legion skill · category **Marketing & Growth**

## When to use
Build a marketing plan: audience, positioning, channels, budget, calendar and KPIs. Use for launching or growing a business.

## Procedure
1. Define target audience and positioning.
2. Choose channels by audience fit and budget.
3. Set budget and timeline.
4. Create content and campaign calendar.
5. Define KPIs.

## Quality checklist
- [ ] Channels match audience
- [ ] KPIs measurable

## Output
Marketing plan.

## Works well with
Legion agents: `growth-strategist`, `seo-specialist`, `social-media-manager`, `content-strategist`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.
