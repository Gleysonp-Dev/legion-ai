# Proofread

> Legion skill · category **Writing & Communication**

## When to use
Proofread text for grammar, spelling, punctuation, consistency and style. Use before publishing anything.

## Procedure
1. Check spelling and grammar.
2. Check punctuation and consistency of terms.
3. Check facts and names.
4. Flag awkward sentences.
5. List changes.

## Quality checklist
- [ ] Changes listed
- [ ] meaning untouched

## Output
Corrected text and change list.

## Works well with
Legion agents: `copywriter`, `content-strategist`, `translator`, `technical-writer`. For large or multi-part work, hand the task to the `legion` skill so the conductor can split it across agents.

## Personalisation
If `~/.legion/memory/profile.md` exists, apply the user's recorded preferences (language, tone, formats, stack) to this procedure.
